# vera-listener

Слушает микрофон и системный вывод ноутбука, распознаёт речь **локально** и
отправляет в мозг Веры выжимку разговора — не дословную расшифровку.

Живёт только на ноутбуке: в `vera3/` его нет и на сервер он не выкладывается.
Серверная половина — `POST /v1/voice/session` (`vera3/services/gateway`).
Подробности и грабли: [`vera3/docs/listener.md`](../vera3/docs/listener.md).

## Установка

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

Скрипт заводит venv в `%LOCALAPPDATA%\vera-listener`, ставит зависимости,
создаёт шаблон конфига и регистрирует задачу планировщика (вход в систему +
вотчдог раз в 15 минут).

## Проверка

```powershell
& "$env:LOCALAPPDATA\vera-listener\venv\Scripts\python.exe" -m vera_listener --probe 15
```

Запускать **из своей сессии Windows**: аудио-устройства принадлежат активной
сессии, из фонового окружения обе дорожки молчат всегда.

## Что уходит в мозг

| Остаётся на ноутбуке | Уходит на сервер |
|---|---|
| аудио (только в RAM, на диск не пишется) | выжимка разговора |
| дословная расшифровка (удаляется после отправки) | с кем, о чём, решения, договорённости, цифры, цитаты |

## Тесты

```bash
pytest tests
```

Тестами покрыта вся логика, не требующая звука: нарезка сессий, отсев,
снятие эха, очередь, отправщик.
