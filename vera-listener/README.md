# vera-listener

Слушает микрофон и системный вывод компьютера, распознаёт речь **локально**
(нейропроцессор/CPU/GPU через OpenVINO, без облака) и отправляет в мозг Веры
выжимку разговора — не дословную расшифровку.

Живёт только на клиентской машине: в `vera3/` его нет, на сервер он не
выкладывается. Серверная половина — `POST /v1/voice/session`
(`vera3/services/gateway`). Подробности и грабли:
[`vera3/docs/listener.md`](../vera3/docs/listener.md).

## Установка на новом устройстве Windows

Пять шагов от чистой машины до работающего слушателя.

### 1. Python 3.12

```powershell
winget install --id Python.Python.3.12 --scope user
```

Установщик сам найдёт его в `%LOCALAPPDATA%\Programs\Python\Python312` —
ничего дополнительно указывать не нужно.

### 2. Код слушателя на диск

Обязательно через `git clone`, не копированием файлов вручную (почтой,
облаком, USB) — `install.ps1` требует UTF-8 с BOM и CRLF, и однажды это уже
стоило того, что установщик не запускался ни разу: любой канал, меняющий
переносы строк, тихо ломает файл. `git` уважает `.gitattributes`, который
держит CRLF, — только он даёт гарантию.

```powershell
git clone https://github.com/zapleoceo/muai.git
cd muai\vera-listener
```

После установки эта папка не нужна для работы — только для переустановки
или обновления, можно оставить как есть.

### 3. Секрет — INTERNAL_SECRET

Слушатель авторизуется на сервере тем же секретом, что и остальные части
Веры. Значение — на сервере, `hetzner-root:/var/www/vera3/infra/.env`,
переменная `INTERNAL_SECRET`. Спроси его у владельца, если доступа к серверу
нет — вписывать наугад бессмысленно, сервер просто откажет.

### 4. Установка

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

Что делает: заводит venv в `~\.vera\listener\venv` (не `%LOCALAPPDATA%` —
там он виртуализирован у упакованных приложений, и задача планировщика
снаружи такого контейнера не находит), ставит зависимости (OpenVINO тянет
~200 МБ, это надолго), создаёт шаблон конфига, регистрирует задачу
планировщика (вход в систему + вотчдог раз в 15 минут) и прогревает модель.

**Прогрев качает саму модель распознавания** (`whisper-large-v3-turbo`,
790 МБ, с HuggingFace) и компилирует её под устройство — в первый раз это
**минуты**, не секунды: на Core Ultra 258V компиляция под нейропроцессор
заняла 141с. Нужен интернет. Дальше слушатель работает офлайн, компиляция
кэшируется.

Установщик создаст `~\.vera\listener.env` с шаблоном и остановится с
просьбой заполнить `INTERNAL_SECRET` — впиши значение из шага 3 и запусти
`install.ps1` ещё раз.

### 5. Проверка

```powershell
& "$env:USERPROFILE\.vera\listener\venv\Scripts\python.exe" -m vera_listener --probe 15
```

Запускать **из своей сессии Windows**, не удалённо: аудио-устройства
принадлежат активной сессии, из фонового окружения (SSH, RDP без экрана,
служба) обе дорожки молчат всегда — это не баг, а как устроена Windows.

Скажи что-нибудь и включи звук в любом ролике/созвоне — `--probe` покажет
кадры и долю речи по обеим дорожкам. Пусто на одной — проверь в Параметры →
Конфиденциальность → Микрофон, что доступ приложениям разрешён.

## Устройство распознавания

По умолчанию `VERA_STT_DEVICE=NPU` — если на машине нет нейропроцессора
(Intel Core Ultra, серии Meteor Lake/Lunar Lake и новее), слушатель сам
откатится на CPU и напишет об этом в лог; ничего настраивать не нужно. Хочешь
задать явно — впиши в `~\.vera\listener.env`:

```
VERA_STT_DEVICE=CPU
```

`GPU` тоже работает (Intel Arc/Iris Xe), но грузит видеокарту, которая может
быть нужна для другой работы — на этом и выбрали NPU по умолчанию для
основной машины (см. `transcriber.py` за цифрами).

## Smart App Control / антивирус

Если Windows режет процесс как неподписанный — `install.ps1` уже это
обходит: задача планировщика запускает не собранный exe, а переименованную
копию настоящего `pythonw.exe` (подпись Python Software Foundation внутри
файла проходит политику). Если всё равно блокирует — смотри
`vera3/docs/listener.md`, там разобран этот случай подробно.

## Переустановка / обновление кода

```powershell
git -C muai pull
powershell -ExecutionPolicy Bypass -File muai\vera-listener\install.ps1
```

Установщик сам останавливает старую задачу, ждёт, пока процесс умрёт, и
ставит новую копию — повторный запуск безопасен.

## Удаление

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -Uninstall
```

Снимает задачу планировщика. Очередь, конфиг и модель остаются на диске
(`~\.vera\listener`) — если решено не возвращаться, удали папку вручную.

## Что уходит в мозг

| Остаётся на устройстве | Уходит на сервер |
|---|---|
| аудио (только в RAM, на диск не пишется) | выжимка разговора |
| дословная расшифровка (удаляется после отправки) | с кем, о чём, решения, договорённости, цифры, цитаты |

## Тесты

```bash
pytest tests
```

Тестами покрыта вся логика, не требующая звука: нарезка сессий (включая
предохранитель по времени), отсев, снятие эха, очередь, отправщик.
