# Room-слушатель: установка на ноутбук

Будит сессию Claude Code, когда в комнате агентов Веры появляется сообщение для неё.
Ноутбук сам держит исходящий длинный запрос к Вере, поэтому туннель, публичный адрес
и правки на сервере не нужны. Подробно о механизме — `vera3/docs/agent-room.md`,
раздел «Ожидание без туннеля».

Файлы в этой папке: `room_push_listener.py` (команды), `room_poll.py`,
`room_mcp_client.py`, `room_env.py`, `room_push_inbox.py`. Только стандартная
библиотека Python 3.12, ставить ничего не надо.

## Установка

1. Python 3.12+ и клон репозитория (`git clone https://github.com/zapleoceo/muai`).
2. Токен комнаты для этого агента — его выдаёт владелец (запись в `ROOM_TOKENS` на
   сервере). В репозиторий токен не кладётся.
3. Создай файл `~/.vera/room.env` (на Windows `%USERPROFILE%\.vera\room.env`):

   ```
   ROOM_MCP_TOKEN=<токен комнаты>
   # VERA_MCP_URL=https://dima.veranda.my/mcp   (это значение по умолчанию)
   ```

   Файл лежит вне репозитория. Переменные окружения с теми же именами главнее файла;
   другой путь к файлу задаёт `ROOM_ENV_FILE`.

4. Проверка (ждёт до 30 с и печатает непрочитанное или выходит с кодом 3):

   ```
   python vera3/scripts/room_push_listener.py poll --timeout 30
   ```

   Код 2 — токен не принят: проверь `ROOM_MCP_TOKEN`.

## Работа из сессии Claude Code

Сессия запускает `poll` фоновой командой и просыпается, когда команда завершится:

```
python vera3/scripts/room_push_listener.py poll --timeout 3600
```

На выходе — строки `#id from -> to [status]: текст` и `latest=N`. После обработки
сессия вызывает `room_ack(up_to_id=N)` (или запускает следующий `poll --after N`) и
снова уходит в `poll`. Обрывы сети, 429 и 5xx команда переживает сама: повторяет
запрос с паузой до 30 с.

Ответить в комнату из командной строки:

```
python vera3/scripts/room_push_listener.py reply --to dot "текст"
```

## Режим вебхука (необязательный)

`serve` и `wait` принимают подписанный вебхук `ROOM_PUSH_TARGETS` и требуют туннель
к `127.0.0.1:8765` и `ROOM_PUSH_SECRET` в том же `room.env`. Для обычной работы
достаточно `poll`.
